# Camera Calibration Service

相机内参标定与畸变校正服务。输入为带唯一帧标识的二维角点观测（多帧、可乱序、
可重复、可损坏），输出相机内参、径向/切向畸变参数与每帧重投影误差，并支持
去畸变与正向映射。全部状态持久化在本地文件系统，不依赖外部服务。

## 快速开始

```bash
uv sync
uv run uvicorn main:app --reload   # 启动 HTTP 服务
uv run pytest                      # 运行测试
```

状态目录由环境变量 `CALIBRATION_STORE` 指定（默认 `./calibration_data`）。

## 坐标约定

* **棋盘/物体坐标系**：三维点 `(X, Y, Z)`，标定板平面为 `Z = 0`，单位任意
  （通常米或毫米），所有帧必须共用同一块板的坐标定义。
* **图像坐标系**：二维像素 `(u, v)`，原点在图像左上角像素，`u` 向右增长，
  `v` 向下增长。
* **投影模型**（针孔 + Brown 畸变）：

  ```
  x = Xc/Zc, y = Yc/Zc                # 归一化相机坐标（Pc = R·Pw + t）
  r² = x² + y²
  x_d = x·(1 + k1·r² + k2·r⁴) + 2·p1·x·y + p2·(r² + 2x²)
  y_d = y·(1 + k1·r² + k2·r⁴) + p1·(r² + 2y²) + 2·p2·x·y
  u = fx·x_d + cx
  v = fy·y_d + cy
  ```

## 求解参数

| 参数 | 含义 |
|------|------|
| `fx, fy` | 焦距（像素单位） |
| `cx, cy` | 主点（像素坐标） |
| `k1, k2` | 径向畸变系数 |
| `p1, p2` | 切向畸变系数 |

求解流程：归一化 DLT 求每帧单应 → Zhang 氏闭式解初始化内参（失败时回退到
`fx=fy=max(W,H)`、主点取图像中心、畸变为零）→ Levenberg-Marquardt 联合优化
8 个内参与每帧 6 自由度位姿，最小化重投影误差平方和。Jacobian 由中心差分
按块稀疏结构计算。

**可配置项**（`SolverConfig`，创建任务时指定）：

* `max_iterations`：LM 最大迭代次数（默认 50）。
* `convergence_tolerance`：收敛阈值（默认 1e-9）。当代价相对下降小于阈值或
  梯度无穷范数小于阈值时判定收敛。
* `initial_damping`：LM 初始阻尼（默认 1e-3）。

**输出**：内参、每帧重投影误差（均值/最大值）、整体 RMS 重投影误差、实际
迭代次数、是否收敛、参与计算的帧 id 列表（`used_frame_ids`，按字典序）。

## 观测校验规则

满足以下任一条件的帧被视为**损坏帧**，拒绝接收（返回拒绝原因），不参与标定：

* `frame_id` 为空；
* 物体点与图像点数量不一致，或点数 < 4；
* 坐标含 NaN/Inf 或维度不符；
* 物体点共线（单应初始化退化）。

相同 `frame_id` 的重复提交是幂等 no-op：首次提交生效，之后静默忽略。
乱序不影响结果——所有帧按 `frame_id` 字典序进入求解。

## 去畸变与边界像素策略

* `undistort_points`：畸变像素 → 去畸变像素（不动点迭代，固定 20 次 /
  容差 1e-12，确定性）。
* `distort_points`：去畸变像素 → 畸变像素（闭式正向映射）。
* `undistort_image`：整图重映射（双线性插值，结果四舍五入到整型）。
  目标像素映射到源图边界外时按 `BorderPolicy` 处理：
  * `clamp`（默认）：钳制到最近的边界像素；
  * `skip`：目标像素置 0。

## 持久化与崩溃恢复

```
<store>/<task_id>/meta.json          任务配置（创建后不可变）
<store>/<task_id>/frames/NNNNNN.json 每帧一个文件，按提交序号命名
<store>/<task_id>/result.json        最近一次已提交的标定结果
```

* 所有写入先写临时文件、`fsync` 后 `os.replace` 原子更名：崩溃不会留下
  半写文件，要么旧状态要么新状态。
* 恢复时按序号重放已提交帧文件，忽略残留临时文件；同一 `frame_id` 只应用
  一次，重启后重复提交不会重复计入。
* 增量重标定是对当前全部有效帧的完整求解，因此与同等有效观测的全量标定
  结果完全一致；被拒绝/重复的帧从未提交，自然不参与计算。

## 并发

同一任务的创建、追加、读取、重标定通过每任务锁串行化，操作可线性化：
任何一次标定/读取看到的都是某一时刻已提交帧的一致快照。所有追加完成后，
最终状态确定（与提交顺序无关），静默任务的重复标定结果逐位一致。

## 数值容差与可复现条件

* **确定性**：相同输入帧集合（任意提交顺序）+ 相同求解配置，输出逐位一致
  （测试中以 `==` 断言，容差为 0）。前提：同一平台、同一 NumPy 构建
  （浮点求和顺序与 LAPACK 实现需一致）。
* **合成数据精度**（9×6 棋盘、10 帧、0.05 px 高斯噪声）：焦距误差 < 5 px，
  主点误差 < 3 px，`k1` 误差 < 0.02，RMS 重投影误差 ≈ 噪声水平（< 0.15 px）。
* **点映射精度**：`undistort_points ∘ distort_points` 往返误差 < 1e-6 px。
* **实际标定精度限制**：闭式初始化依赖 ≥ 3 个不同姿态的平面视图；姿态
  退化（近平行、覆盖区域小、点集中于图像一隅）会显著降低可观测性；
  模型仅含 `k1, k2, p1, p2`，更高阶畸变（如 k3、鱼眼）不在模型内，
  残差会系统性偏大。

## HTTP API

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/tasks` | 创建任务（重复创建返回 409） |
| `POST` | `/tasks/{id}/observations` | 追加观测帧，返回被拒绝帧及原因 |
| `POST` | `/tasks/{id}/calibrate` | 对当前有效帧重新标定并持久化结果 |
| `GET` | `/tasks/{id}/result` | 读取最近一次已提交结果 |
| `POST` | `/undistort/points` | 畸变像素 → 去畸变像素 |
| `POST` | `/distort/points` | 去畸变像素 → 畸变像素（正向映射） |
